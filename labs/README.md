# 🧪 Broken Access Control — Practical Labs

Welcome to my hands-on Broken Access Control (BAC) laboratory.

This section documents my practical learning and vulnerability testing through **PortSwigger Web Security Academy**.

The objective is to understand how access control vulnerabilities occur, identify weaknesses through practical testing, analyse HTTP requests and responses, and understand how developers can prevent them.

## 🎯 Learning Objectives

- Understand different types of access control mechanisms.
- Identify missing and incorrectly implemented authorization checks.
- Practise vertical and horizontal privilege escalation.
- Understand and test IDOR vulnerabilities.
- Investigate unprotected functionality and endpoint bypasses.
- Analyse parameter-based and context-dependent access controls.
- Practise HTTP request manipulation using Burp Suite.
- Understand vulnerabilities in multi-step processes.
- Learn how to identify and prevent authorization weaknesses.
- Develop a structured penetration-testing methodology.

## 🔬 Lab Methodology

Each lab follows this process:

1. **Understand** — Study the vulnerability and its underlying concept.
2. **Explore** — Examine the application and identify its functionality.
3. **Intercept** — Inspect HTTP requests and responses using Burp Suite.
4. **Hypothesize** — Identify possible authorization weaknesses.
5. **Test** — Experiment with requests and parameters.
6. **Exploit** — Demonstrate the vulnerability in the authorized lab.
7. **Analyse** — Understand the root cause and security impact.
8. **Prevent** — Study the appropriate remediation.
9. **Document** — Record findings, evidence and key takeaways.

## 📖 Documentation Standards

Every completed lab should include:

- Lab objective and vulnerability category
- Reconnaissance and observations
- Relevant HTTP requests and responses
- Testing and exploitation methodology
- Evidence and screenshots
- Root cause and security impact
- Prevention and remediation
- Personal learning and takeaways

Only exercises actually attempted and verified will be marked as completed.

## ⚠️ Scope and Ethics
