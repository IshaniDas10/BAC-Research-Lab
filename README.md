# BAC Research Lab

**Broken Access Control Research & Testing Toolkit**

A hands-on cybersecurity research repository focused on understanding, identifying, reproducing, testing and preventing Broken Access Control vulnerabilities.

## Objectives

- Study Broken Access Control in depth.
- Understand access-control models and authorization mechanisms.
- Explore OWASP A01 and related security weaknesses.
- Reproduce vulnerabilities in controlled testing environments.
- Develop Python-based authorization testing tools.
- Compare vulnerable and secure code implementations.
- Document practical penetration-testing methodologies.

## Research Areas

- IDOR and BOLA
- Horizontal and Vertical Privilege Escalation
- Forced Browsing
- Mass Assignment
- JWT and Session Authorization
- CSRF and CORS
- Path Traversal and SSRF
- Business Logic Authorization
- Multi-Tenant Access Control
- API Authorization

## Learning Approach

Each vulnerability will be studied through its definition, root cause, exploitation methodology, impact, detection, prevention and practical testing.

## Ethics

All testing is restricted to intentionally vulnerable labs, systems owned by the researcher, or systems for which explicit authorization has been obtained.
